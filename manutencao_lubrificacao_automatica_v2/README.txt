## Novidades desta versão
- Interface mais profissional e elegante.

- Código automático do relatório.

## Como usar
1. Extraia o ZIP.
2. Abra o arquivo index.html no navegador.
3. Faça login com ELISON / 123456.
4. Preencha o checklist.
5. Finalize a manutenção.
6. Use o botão "Enviar via WhatsApp" no relatório.

## Observação
Os dados ficam salvos no navegador usando localStorage.
Para uso em vários computadores ou celular com banco de dados online, será necessário evoluir para uma versão com backend.
