# Lubrificantes e Filtros - U&M

Aplicativo para consulta offline de lubrificantes e filtros por equipamento.

## Funcionalidades
- 🟢 Design personalizado com a identidade visual U&M.
- 📱 Interface otimizada para dispositivos móveis (Android e iOS).
- 🔍 Busca rápida por nome, modelo ou categoria.
- 🛢️ Listagem detalhada de compartimentos, fluidos e filtros.
- 💬 Botão flutuante para suporte via WhatsApp.

## Como usar no iPhone (iOS)
1. Abra o link do GitHub Pages no Safari.
2. Toque no botão de compartilhar.
3. Selecione **"Adicionar à Tela de Início"**.
